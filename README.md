## AI Acknowledgment Statement

This project utilizes Artificial Intelligence (AI) tools, specifically Google Gemini 2.5, to enhance various aspects of development and documentation. AI has been employed in the following capacities:

*   **Code Generation:** Assisting in the generation of boilerplate code, function definitions, and example usage snippets.
*   **Code Explanation and Refinement:** Providing explanations for complex code sections, suggesting improvements for readability and efficiency, and generating inline comments and docstrings.
*   **Documentation Support:** Drafting and structuring markdown content for the `README.md` file, including this acknowledgment statement.
*   **Algorithmic Design:** Assisting in conceptualizing and outlining algorithms, and potentially generating visualizations like flowcharts.

All AI-generated content has undergone rigorous human review, verification, and critical evaluation to ensure accuracy, relevance, and adherence to project requirements. The ultimate responsibility for the integrity and correctness of the project's content lies with the human developer(s).

This approach aligns with Monash University's guidelines on acknowledging AI usage in academic and project work, promoting transparency and responsible innovation. The AI tools served as assistants to accelerate development and improve clarity, rather than acting as autonomous creators.
