# Data

The raw data is **not** stored in this repository (it is ~9 million rows and is
provided by Monash Smart Infrastructure for unit use only).

1. Download `5occupancySensor_MayToDec2024_9MRows.csv` from the MMA3001 Dataset 2
   Google Drive folder.
2. Place it at `data/raw/5occupancySensor_MayToDec2024_9MRows.csv`.
3. **Do not open and save it in Excel** - Excel silently truncates files to
   1,048,576 rows. Check the file has 9,091,732 data rows.

Despite its name, the file covers November 2023 to April 2026.
